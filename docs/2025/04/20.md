# 哈喽哈喽👋

故事的序章，始于2025年的暮春。

4月20日，夜色初临。21点22分，我怀着莫名的悸动，按下了那个小小的“添加好友”按钮，像是向一颗遥远的星球发出了第一串微弱的电波。

幸运的是，信号很快便有了回响。六分钟后，21点28分，申请通过。我们的世界，在此刻轻轻相连。

我有些紧张，也有些雀跃，在21点35分，小心翼翼地发出了第一声问候：“哈喽哈喽👋”——这简简单单的四个字，便是我对你说的第一句话。

从那之后，时间仿佛被按下了快进键。我们聊着，笑着，从陌生到熟悉。不知不觉，屏幕上的时间跳到了22点55分。那个夜晚，因你而变得短暂又漫长。
